# Victor Eduardo Rivera Corona — Portafolio de Desarrollador

Sitio web personal construido con HTML5 semántico, CSS3 moderno y JavaScript vanilla.

## 🚀 Demo en vivo

https://KAizuto846.github.io/portafolio/

## ✨ Características

- HTML5 semántico (header, nav, main, section, article, aside, footer)
- CSS3 con custom properties, Flexbox y Grid, mobile-first
- Responsive desde 320px hasta 4K con 4 breakpoints
- 100% accesible (Lighthouse 100 en accesibilidad, 95+ en performance)
- Modo oscuro con preferencia del sistema y localStorage
- Menú hamburguesa, scroll suave y formulario con validación
- Proyectos cargados dinámicamente con fetch
- Meta tags Open Graph para compartir en redes

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, custom properties)
- JavaScript ES6+ (módulos, fetch, async/await)
- Git y GitHub para control de versiones
- Lighthouse para auditoría de calidad
